# Code of Conduct

## Our commitment

We want Multi Language Learn to be a welcoming, respectful and productive project for everyone, regardless of experience, background, identity or point of view.

## Expected behavior

- Be respectful, constructive and considerate.
- Discuss ideas and code, not people.
- Give useful context when reporting a problem.
- Accept feedback and different technical perspectives.
- Protect private information and project credentials.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, sexualized behavior, doxxing, deliberate disruption, malicious content and sharing private information without permission are not acceptable.

## Enforcement

Project maintainers may remove or edit comments, reject contributions, or restrict participation when behavior violates this code. Report concerns privately through the repository's GitHub contact channels and include enough context to investigate. Reports will be handled as confidentially as practical.

This code applies to project spaces and public interactions where someone represents the project.
